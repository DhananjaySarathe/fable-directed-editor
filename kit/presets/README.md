# Presets

Named, approved edit styles. When the user names one, read its README first and follow it; its numbers win over the
generic defaults in `kit/refs/EDITING.md`.

Every preset starts from `kit/refs/OWNER_DEFAULTS.md` (the owner's standing taste) and the planning gate in its §8
(`visual_plan.json` → `kit/hf/plan_check.py`, then precheck with its ambition section at 0 HIGH).
