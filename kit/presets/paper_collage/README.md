# preset_paper_collage: photoreal objects on paper, stamped type, marker ink (2026-10-11)

> **Read first, every edit:** `kit/refs/OWNER_DEFAULTS.md`, the owner's standing taste. It holds in every preset; this
> file can be stricter, never plainer. **Before the template is written, the planning gate:** `kit/refs/SCENES.md` →
> `visual_plan.json` → `python3 kit/hf/plan_check.py visual_plan.json` (0 errors). Pick the components from
> `kit/hf/registry.json`, starting with `python3 kit/hf/tools/registry.py --unused`. After the build,
> `kit/qa/precheck.mjs` must show 0 HIGH, ambition section included (OWNER_DEFAULTS §8).

The owner's request: "I love this kind of thing ... this is going to change our whole shorts editing." The reference is a
fliki reel, [instagram.com/p/Dcblnu1gyAP](https://www.instagram.com/p/Dcblnu1gyAP/). It was studied frame by frame in the
browser on 2026-10-11 (visuals only, not heard). Its structure:
- **0–6 s, the hook:** a collage on aged paper, a beat every ~0.6–1 s, over the caption band and the presenter below.
- **6–19 s:** the product's screen recording on top.
- **20–27 s:** the face, full screen.

The look is new and not yet used on a real film. Validate it on the first Reel that uses it.

## 1. What the look is (observed)

- **The world:** cream aged paper, faint newspaper columns, stains and grain, a soft vignette. One continuous slow camera
  push, no cuts inside the collage.
- **Hero objects:** a photoreal object (the reference's: a toy) cut out with a soft contact shadow, idling a little.
  This is the "hyper-realistic" part. In the reference it is a generated image; here it comes from his photos or
  images he generates.
- **Stamped headlines:** heavy condensed caps (Anton), black with one red word, each line slamming in on its phrase.
- **Paper props:** masking-tape labels in typewriter caps, polaroids thrown in at an angle, torn red price tags, a
  yellow ticket with one huge number, a newspaper clipping, a phone showing the object.
- **Red marker ink:** circles around the number, curved arrows, handwritten notes ("It's a status. It's a flex.").
- **Data:** a hand-drawn chart on graph paper whose line draws itself, with price tags stuck on the points. In the
  reference, a halftone world map with dashed arcs and pins.
- **Captions:** bold white caps on a dark band between the collage and the face, the spoken word highlighted in pink.

## 2. When to use it (and when not)

- **Use it** for a Reel's hook (the first 3–6 s) and for explainer beats about a thing: a product, a price, a trend,
  a comparison of costs, a "this is everywhere" moment. It suits topics with a physical or iconic object.
- **Don't use it** for a real workflow demo: the screen recording is the evidence (EDITING.md §11), and a collage of it
  would hide it. Don't use it for a whole long-form either: the reference uses it for 6 s, then shows the product.
- **Layout (9:16):** the collage panel on top (y 0–1080), the caption band, his face below (HF.reel slots), as in the
  reference. Or a full-frame collage takeover for 2–5 s, then back to the face.

## 3. The parts (kit/hf/paper.js, with HF.reel or HF.studio)

```js
const P = HF.paper(S, { seed: 11 });                 // vendor.inline includes paper.js, annotate.js, collage.js
P.bg(L, { x: 0, y: 0, w: 1080, h: 1080, news: ["his", "own", "words"] });   // texture only (data-decor)
P.hero(L, "assets/cut/toy.png", { x, y, h: 760, at: W(3), from: "rise" });   // a cut-out from kit/look/objects.py
P.stamp(L, "this toy is|*everywhere.", { x: 60, y: 120, size: 120, times: [W(5), W(8)] });  // a line per phrase
P.tape(L, "labubu", { x, y, at });   P.tag(L, "$0.90 · haiku 5.5", { x, y, at });
P.ticket(L, { title: "rare edition", value: "$2,450", sub: "sold", x, y, at });
P.polaroid(L, "assets/cut/photo.png", { x, y, w: 340, rot: 6, at, caption: "his words" });
P.chart(L, { x, y, w: 700, h: 460, values: [..his numbers..], labels, at, title: "prices surge" });
P.phone(L, "assets/cut/screen.png", { x, y, h: 640, at });
const ink = P.ink(L); ink.circle([x, y, w, h], t); ink.arrow([x0, y0], [x1, y1], t); ink.note(x, y, "his words", t);
```

Every element is thrown in on a snappy spring (~1 % overshoot), a pure function of time. It is hidden before its time,
also on frame 1. Sounds come built in: a select click as each prop lands, a bass hit per stamped line, a slide as the
chart line draws. They are given at the moment they land (kit/audio/mix.py aligns the attack) and thinned to 6–12
small ones a minute.

## 4. Hero objects: where the photoreal images come from

The look needs 1–4 photoreal objects per Reel. Nothing on this Mac generates images, so the order of preference is:
1. **Real:** his own photo of the thing (the phone, the laptop, a product), shot on a plain wall. Or a screenshot.
2. **Generated by him in ChatGPT** (his existing subscription, the same way he makes thumbnails). Claude writes one
   prompt per object, in a consistent style so the objects look like one set:
   > Photorealistic studio product photo of **<the object, exact and specific>**, single object, centered, whole object
   > in frame with margin, plain light-grey seamless background, soft key light from the upper left, gentle contact
   > shadow, sharp focus, true-to-life materials and colours, no text, no logo, no hands, vertical 3:4.

   No real people's faces, no brand logos unless he names the product, no fake documents.
3. **Paid generators** (any image MCP connected to this session) only with his explicit OK for that use; they bill
   credits.

Then put the files in `films/<name>/assets/objects/` and run `uv run python -m kit.look.objects films/<name> --stage`.
Apple Vision cuts each one out (~1 s, on-device) into `assets/cut/<name>.png`. A file Vision can't separate is reported:
regenerate it on a plainer background.

## 5. Rules (each one: trigger, exception, fallback)

- **Pace:** one new element per spoken phrase, 0.8–1.6 s apart in the hook; the hero holds at least 1.5 s.
  Exception: a list ("Reels, TikTok, Shorts") can land item by item on its words. Fallback: if the hook is longer
  than ~6 s, cut to the face or the screen recording; the collage is a hook, not the whole Reel.
- **Truth:** every number on a ticket, tag or chart is one he said or showed. The objects are illustrations. Generated
  people never stand in for real people. Exception: none. Fallback: if a number isn't in the take, leave it off.
- **Readable on a phone:** stamp ≥ 90 px, labels ≥ 36 px on 9:16 (precheck "small"). The newsprint texture is marked
  decorative and is exempt. Fallback: drop a prop rather than shrink it.
- **One red:** red is for the word or number that matters (a stamp's last word, the circled number, the tag). Black
  carries everything else.
- **Grade:** when the collage sits above his face, his footage keeps its look v2 grade; don't warm his skin to match
  the paper.

## 6. Building a Reel in this look (ordinary path: kit/reel)

1. The hook plan (EDITING.md §4) picks the collage beat. List the objects and their sources (§4), the stamp lines
   (his words) and the props, each on a word id.
2. Get the objects (his photos / his ChatGPT images from Claude's prompts), then `python -m kit.look.objects ... --stage`.
3. In the Reel's `src/template.html`: `const P = HF.paper(S)`, a `layer()` for the collage, the props on their words.
   The skill `paper-collage` covers this step and can hand it to a cheaper model (see the skill).
4. `python -m kit.reel films/<name> render`: precheck (layout, sizes, reading time), the mix, then qa --holds.
