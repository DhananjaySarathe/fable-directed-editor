# Why our edits use so little of the kit (audit, 2026-10-20)

The owner: "There are a lot of good and awesome animations, but when we are editing a video, our video sucks... we are
hardly using a few of them... every time I have to tell you again and again."

Measured on all 21 film templates (`films/**/template.html`) against the kit (`kit/hf`: 25 modules, ~6,500 lines, ~60
components).

## 1. Usage

- **Never used in any film (30):**
  - collage and torn paper;
  - the terminal, the token race (`tokens`), `race`, `compare`, `phone`;
  - evidence `focus`, `scoreboard`, `flow` (called "the standard since 2026-10-10");
  - 9 of the 11 Reel scenes (ideaCards, connect, scanGrid, week, clock, bars, notif, prompt, toolPair);
  - 12 of the 18 UI cards (pr, hub, doc, message, numbered, tiles, column, toggle…);
  - the redline and paper looks.
- **Used once:**
  - sketch, annotate, scribble, scramble and stack (all in ai-workflows);
  - diagram and screen (expensewaale);
  - code and kinetic (xchakra).
- **Stickman:** 3 films, none recent.
- **Components per film:** 0-13 distinct types (median ~4). The rest of each template is 150-900 lines of one-off HTML.

## 2. Root causes (most important first)

1. **Each look is a separate world with its own small toolkit, and the default keeps changing.** There are seven looks
   in two weeks:
   - paper_studio;
   - pastel_box (the default 10-10);
   - night + night_reel;
   - redline;
   - paper_collage;
   - canvas_studio (the default 10-20);
   - the Reel kit.

   Each ships its own world and a handful of components. The older components (stickman, sketch, annotate, collage,
   evidence) were never wired into the newer looks, so using them means restyling them by hand. An edit therefore
   doesn't.
2. **The worked example is the real spec.** A preset README points to one film's template, and a new edit copies that
   template's subset. Nothing asks "which of the ~60 components fits this passage?".
3. **The planning gate that would force variety is dead.** `kit/refs/SCENES.md` (explanation type → technique) and
   `kit/hf/plan_check.py` (technique runs, words-only share, stickman budget) are well designed, but:
   - `kit/hf/registry.json` lists 25 ids from the paper_studio era and misses ~40 newer components (studio/reel cards,
     kinetic, evidence, sketch, annotate, collage, agent, footage, canvas…);
   - the default presets' READMEs never call the planner;
   - no film has a `visual_plan.json`.
4. **QA measures defects, not ambition.**
   - precheck / qa.py / the critic catch broken text, freezes and levels.
   - Nothing measures component diversity, layout share or the longest stretch without a new element.
   - `HF.box.pace` is computed (`window.__pace`) but never checked.
   - So the critic finds "53 % face-beside-graphic" only after a draft render (xchakra, round 1).
5. **The owner's taste lives in chat and scattered memory, not in the default.** "Hook in ≤10 s with the stakes on
   frame 1, fast, music ~12 dB under, animations that explain the differences, me in corners/cards, no cut-out,
   standalone Reels" is restated per video. The first cut follows the latest brief literally ("not so much text") and
   comes out plain.
6. **Film code is copied, not shared.**
   - Every film has its own `edl.py` / `build.py` / `audio.py` (2,265 lines of `edl.py` alone).
   - `render4k.py` exists as three copies.
   - Fixes don't propagate, and each film re-learns the same bugs.

## 3. Kit bugs that make components risky to use (all hit on xchakra, 2026-10-20)

| bug | where | effect |
|---|---|---|
| The Reel kit forces a portrait A-roll | `kit/hf/reel.js:79-82` | a 16:9 camera in a Reel framed the wall; both Reels broke on the first render |
| Reel `say()` never records word times (`_a`) | `kit/hf/reel.js` say/rise vs `studio.js:144` | anything timed to a line's container (plates, focus) silently fails; plates sat on screen for the whole Reel |
| `line()` accent: only a leading `*` | `studio.js:176-177`, `reel.js:175-176` | `*word*` (the kinetic syntax) prints a literal `*` |
| Box jump cuts: full frame only | `studio.js:264` (`S.box({ jumps })`) | jump cuts inside a card play on identical framing |
| `strike()` / stamps / notes on FRONT have no lifetime | `studio.js:185` and callers | two red strike lines stayed on screen for 4 minutes (draft 2); precheck ignores non-text |
| precheck: text under an opaque chapter/title card counts as "over the face" | `kit/qa/precheck.mjs` (face check) | false HIGHs force timing workarounds |
| The `HF.code` title bar is 16 px | `kit/hf/code.js` (`HF.win` title) | fails the kit's own 32 px floor |
| `reel.js` isn't in `vendor.MODULES` | `kit/hf/vendor.py:23-40` | every Reel pipeline must remember to add it |
| No kit-level re-listen for a film's own cut | per-film `edl.py` | aligner drift chopped or leaked words at 6 joins; caught only by ad-hoc whisper checks |
| The 4K chunk renderer exists only as film copies | `films/*/render4k.py` | long films re-discover the chunking |

## 4. Fix plan (in order)

1. **Quick wins (half a day):**
   - fix every bug in §3;
   - generate `registry.json` from the module headers so it lists every component (with a "works in looks: …" field);
   - add an ambition check to precheck: layout share, distinct components per minute, the longest stretch with no new
     element, and the box pace;
   - write one `kit/refs/OWNER_DEFAULTS.md` (his standing taste, read first by every edit).
2. **Make planning mandatory.** Every preset's workflow starts with `visual_plan.json` → `plan_check.py`. Add rules:
   - every explanation type maps to its technique;
   - at least ~6 distinct techniques per minute of long-form;
   - stickman 2-4 moments;
   - hand-made styles 2-3 per video;
   - no layout over 35 %.
3. **One kit, many looks.** Components take theme tokens (colours, fonts, plate style) from the active look instead of
   hard-coding one look, so stickman / sketch / annotate / collage / evidence / UI cards render in any preset. Stop
   forking a new component set per preset.
4. **A shared film pipeline.** A `kit/film/` package (cut with frame-grid and join re-listen, build, mix, chunked 4K,
   Reels-from-film) so a film is its cut list + its scene plan + its template.

## 5. Phase 1 done (2026-10-20): changelist

Every §3 bug has a fix and a repro in `kit/hf/demos/audit/` (fixture pages: a 16:9 HF.studio page and a 9:16 HF.reel
page with a 16:9 camera). Run `node kit/hf/demos/audit/check.mjs`: 20 checks, all ok.

| bug | fix |
|---|---|
| Reel forces a portrait A-roll | `HF.reel(..., { src: [w, h] })` sizes the video and the box to the camera; the default is still portrait |
| Reel `say()` has no word times | Reel `rise`/`wordsOut` record `_a`/`_h`; `say()` sets `data-w` and returns `t0` (as studio does) |
| `line()` accent: leading `*` only | `HF.accentTokens` (core.js) in both `line()`s: `*word`, `*word*`, `*several words*`; the closing `*` never prints |
| Jump cuts: full frame only | `HF.box.cutsOf(pieces)` + `HF.box.jumpShots`: every cut inside a held shot reframes on its slot (full 1.12x punch / back; a card's footage 1.0 / 1.1); the active shot is picked by time; a cut that already has a shot (a film's own jump) is skipped. On by default in `S.box()` (studio and reel) |
| `strike()` on FRONT never ends | `strike(..., until)` fades it out at `until`; precheck's new `linger` check catches any small part on a full-frame layer that is up 20 s or more with no end |
| precheck: text on a chapter card is "over the face" | the face check skips text on an opaque full-frame cover (`[data-cover]`, or a full-frame ancestor or sibling with an opaque fill) |
| `HF.code` title bar 16 px | the window's URL/title bar is marked `data-decor` (window chrome, which precheck already exempts for `.tbar`); a file name that matters goes in a label |
| `reel.js` not in `vendor.MODULES` | `vendor.MODULES` includes reel.js, footage.js, agent.js and night_reel.js, and `inline()` dedupes, so older builds that append them still work |
| No re-listen for a film's own cut | `kit/cut/relisten.py` already had the library (used by `cutcheck --media`, which needs the takes' analysis). It now has a command line that reads the joins and words from the film's own edl.json: `uv run python -m kit.cut.relisten <edl.json> <vo.wav> [--hinglish] [--at=]`. On xchakra (3 joins) it passed 2 and flagged the Hinglish join at 0:21.3 |
| 4K chunk renderer only as film copies | `kit/hf/render4k.py <film dir or hf dir> [--plan]`. Its plan for xchakra matches the delivered render (10 chunks, 8,208 frames). The three film copies are left as they are (finished films) |

## 6. Phase 3 done (2026-10-20): components that follow the look

Root cause 1 (§2): every look was its own world, and the older components only looked right in the look they were
born in. They now read the active look's tokens. The mechanism already existed (components share `HF.C` by reference),
but frames only ever set the accent.

**What changed:**
- **`HF.look(name, overrides)` and `HF.LOOKS` (core.js).** There are six token sets: pastel_box, canvas_studio,
  redline, night, paper_studio and paper_collage. Each holds:
  - colours: paper, card, sunk, line, ink, text, ink2, sub, mute, acc/accTint, ok/okTint, bad/badTint, warm, onFill,
    onVideo, plate, shadow, shadowSoft, cardLine;
  - fonts: body, mono, code, display (+ weight, tracking), hand, stamp;
  - dark, and a default code theme.

  The call fills `HF.C` and `HF.F` in place, writes the CSS variables on `<html>`, and points `HF.HAND` at the look's
  hand.
- **Every frame applies its look:**
  - HF.studio and HF.reel apply pastel_box, with the film's palette as overrides;
  - HF.canvas, HF.redline, HF.night and HF.nightReel apply their own;
  - `HF.paper(S, { look: true })` applies paper_collage;
  - `o.look: false` opts out;
  - with no frame, paper_studio is the default.
- **The shared CSS reads the variables.** That covers studio/reel's `.card .chip .tbar .pill .lbl .who .txt .mention
  .cell .sv .mono .cap` and paper.css's `.hf-card .hf-pill .hf-win .hf-code .hf-serif .hf-lbl`.
- **Converted to tokens:**
  - studio_ui (all 18 cards);
  - evidence (flow, scoreboard; focus via layers);
  - code (theme defaults to the look's, so night gets dark code; the highlight band follows the accent);
  - diagram;
  - scenes.js (compare, chat, the chapter pill, end card);
  - sketch and annotate (the hand font, and a dark halo on dark looks);
  - the stickman (ink, paper, prop surfaces, type).

  They keep their content colours (avatars, a Slack sidebar, the orb).
- **`HF.parts(K, ROOT, { front })` (studio.js)** holds the frame-independent pieces plus `.ui`, focus, scoreboard, flow,
  hold and quiet. HF.studio now builds its helpers from it (one copy). HF.canvas exposes `C.parts`, `C.ui`,
  `C.scoreboard`, `C.flow` and `C.focus`: before this, a canvas film couldn't use any S-based component.
- **Two fixes the check found:**
  - The checklist's "next →" tag and the PR card's "Open" pill went from 20-22 px to 26-32 px.
  - Code windows got their own font token (JetBrains Mono everywhere). Redline's Martian Mono pushed lines out of the
    window.

**The check:** `node kit/hf/demos/looks/check.mjs` builds one fixture page per look (a PR + stamp, checklist + note,
scoreboard + flow, code + compare, sketch + stickman + note). For each scene it measures every text against the
background it really sits on, finds broken markup and page errors, and writes `output/temp/demos/looks/sheet.png`.
- **All six looks pass:**

- **One bug only the eye caught.** The first sheet had tiny card text. The font tokens were double-quoted
  (`"Inter", sans-serif`) and ended innerHTML `style="..."` attributes early. The tokens are now single-quoted, and the
  check flags any cut attribute.

## 7. Phase 4 done (2026-10-20): the shared film pipeline (`kit/film/`)

Root cause 6 (§2): every film copied its own `edl.py` / `build.py` / `audio.py`, so fixes didn't carry over. A film is now
its recipe, and every step runs from the kit. Read `kit/film/README.md`.

**What a film is:**
- `films/<name>/film.py`: SOURCES, KEEP, JUDGED, the fixes, SPELL / TEXT / RESPELL, MUSIC and REELS;
- `visual_plan.json`;
- `src/template.html`;
- `reels/<r>/template.html`.

xchakra alone needed 965 lines across edit.py, edl.py, build.py, audio.py and its Reels' cut.py and build.py. The
example's film.py is 60 lines.

**The package** (~1,270 lines; one CLI: `uv run python -m kit.film <film> prep|cut|joins|build|cues|precheck|mix|draft|
render|mux|reels|snap|paths`):

| module | what it holds | taken from |
|---|---|---|
| `config.py` | film.py + defaults, multi-source word ids (base, cold-open COPY), the fix maps, the folders (all under output/, edl.json included) | the films' headers, kit/reel/config.py |
| `cut.py` | the cutcheck gate; words with TIME_FIX / START_FIX / END_FIX / IN_AT / OUT_AT; edges in quiet (kit/cut/edges.py), joints, slivers; per-source speed; views (a piece split where the recording changes); the voice (one cut, hsin fades, none inside a continuous run); one picture track per name; faces; the joins step (envelope audit + `kit.cut.relisten`) | ai-workflows, reverse-engineer, xchakra edl.py; kit/reel/edl.py |
| `build.py` | staging, vendor.inline, `D = { total, talk, pieces, words, caps, tracks, faces? }`, `__TOTAL__` / `__TALK__` / `__END-<s>__`, RESPELL placed on its sound (kit/cut/respell.py), captions.srt, cues, precheck, lint, snapshots | the films' build.py, reverse-engineer's film_respelled() |
| `mix.py` | MUSIC beds (`w<id>`, `tag:<tag>`, `end-<s>`) into kit/audio/mix.py | kit/reel/build.py beds() |
| `render.py` | the 1080p draft → mux → qa.py; the 4K render through kit/hf/render4k.py → mux → qa.py | the films' build.py --mux, kit/reel render() |
| `reels.py` | Reels from the finished film by whole sentences (its voice, tracks and spelled words) | xchakra and reverse-engineer shorts/cut.py |

**The frame grid, one recipe.** Each piece's picture is cut with `-ss` a quarter frame early, then
`fps=FPS:round=down,trim=end_frame=n`. Every track's frame count is checked against the timeline.

**Bugs the example found (all fixed in kit/film):**
- **`-ss` at 4 decimals skipped a frame.** 17/30 is written as 0.5667, which is past the frame's own time, so `-ss`
  dropped that frame. Every piece starting on a frame 2 mod 3 ran a frame late: 5 of 12 pieces on the example,
  measured on the edge frames against the source. After the fix, all 24 edge frames are exact. A copy of the take
  shifted 0.02 s (Framecast's offset) also gives 1078 of 1078 frames, every edge on its own frame, and even 1/30 s
  packet spacing.
- **`tpad` after a concat padded 2 of 12 frames.** The Reel's tail came out short (282 of 292). `fps=FPS` before the pad
  fixes it.
- **The voice inside a Reel slipped about 5 samples.** At continuous joins, `src_a` and `out_a` were rounded
  separately. Audio is now placed by frame (1600 samples a frame), and the Reel's voice equals the film's sample for
  sample.
- **Splitting a Reel at each film piece's own span dropped the film's pauses.** Each sentence was glued to the next.
  The split is now at piece starts, so the pause after a piece stays with it.
- **The kit:** `ui.numbered` turned only the first `|` into a line break (studio_ui.js; now all of them).

**The example** (`kit/film/example`) is a check film: ffmpeg's test pattern plus a `say` voice with a retake, an aside
and an in-sentence pause. All of this ran on 2026-10-20:
- **prep.** shorts probe and analyze.
- **cut.** cutcheck PASS; 12 pieces, 35.93 s. The retake and the aside are out. The 0.8 s pause became a 0.17 s
  sliver. The cold-open copy has ids + 10000. TIME_FIX re-timed "The": the aligner had it 1.2 s early, so the piece
  would have opened on 1.2 s of air.
- **joins.** 0 edges in a sound; 11 of 11 joins re-listen ok.
- **plan_check.** 0 errors, 0 warnings.
- **precheck.** 0 HIGH, 0 MEDIUM. Ambition: 8 components out of the 4 needed, top layout 27 %, longest still 2.0 s.
- **The 1080p draft.** Rendered in 40 s; qa.py PASS (1920x1080, 30 fps, 35.93 s, −14.0 LUFS, TP −2.0). The mix:
  music 13.2 dB under the voice, no dropouts, 7 of 18 cues played.
- **Reel a.** reels → build → draft: 0 HIGH / 0 MEDIUM, 5 components, qa.py PASS (1080x1920, 10.50 s, −14.0 LUFS).
- **Also exercised in memory:** talk at 1.06x, views splitting pieces continuously by kind, and a second track that
  is black outside its kind (both tracks 1019 of 1019 frames).

**Regression.** `node kit/hf/demos/audit/check.mjs` and `node kit/hf/demos/looks/check.mjs`: all ok.
`registry.py --check`: ok.

## 8. kit/film, part 2 (2026-10-20): prep, the grade, room tone and the first 4K

§7 left these per film: voice cleaning, the look v2 grade of the cut, ROOM_TONE, and the 4K path. They are now in the
kit, so a multi-take film needs no prep.py, voice_eq.py or grade_cut.py of its own.

- **`prep` (kit/film/prep.py)**, from films/reverse-engineer prep.py + voice_eq.py, films/ai-workflows prep.py and
  kit/reel prep.py:
  - words: `shorts probe` + `analyze`;
  - `picture=True`: a CFR SDR copy of the original at the film's FPS, HLG tone-mapped. shorts probe keeps a 16:9 take
    at 1080p, and the cut uses this copy for a 4K film;
  - `clean=True` or `dict(mic, declip, dereverb, eq)`: adeclip, two-mic WPE, then DeepFilterNet3;
  - the measured EQ: each cleaned voice against one speech target, plus a gain to −21 LUFS. The cut's voice chain then
    becomes that EQ, an expander, a de-esser, compression and −19 LUFS;
  - **WPE runs only when the two channels differ.** reverse-engineer's identical-channel take was cancelled to
    −61 LUFS. On the example, prep printed the skip and went on.
- **`ROOM_TONE` (cut.py)**: kit/reel's, made per source. Each source's quietest 0.8 s with no word is looped under
  that source's own stretches, with 50 ms ramps.
  - Before: the example's DeepFilterNet voice had 175 windows of 50 ms near digital silence (down to −118 dB).
  - With room tone at 0.0: vo.wav has none, and its quietest window is −76 dB.
- **`grade` (kit/film/grade.py)**, from films/ai-workflows/grade_cut.py: look v2 on the cut's camera track.
  - One shot per take and view kind; the face track is the cut's own.
  - `<track>_graded.mp4` keeps the same frames (checked: 1078 of 1078 in 53 s on the example).
  - Build and reels use it while it is newer than the cut. `render` refuses an ungraded track while GRADE is set.
  - **His room stays as shot by default** (OWNER_DEFAULTS §2): vignette 0 and no matte. A matte, a vignette or other
    v2 numbers are opt-ins.
- **One kit/look change:** `GRADE_V2_SET` (kit/look/v2.py `params()`), e.g. `vignette=0,bg_stops=0`, sets v2 numbers
  last. It is read from the environment so the worker processes get it; unset, nothing changes. Checked on one frame:
  - with `vignette=0`, the corners gain like the centre (1.074 against 1.089: the face key light);
  - the stock natural look darkens them (1.038).

**The example, re-run on all of it** (`clean`, `ROOM_TONE = 0.0`, `GRADE = dict(look="natural")`):
- **prep.** WPE skipped (identical channels); DeepFilterNet3 and the measured EQ applied.
- **cut.** cutcheck PASS, the same 12 pieces.
- **joins.** 11 of 11 ok on the cleaned voice.
- **grade.** 1078 of 1078 frames.
- **draft.** precheck 0 HIGH / 0 MEDIUM; qa.py PASS (−14.0 LUFS); no dropouts.
- **Reel a.** Re-cut from the graded track; precheck 0 / 0, qa.py PASS.
- **The first 4K render** (`render`, kit/hf/render4k.py with 3 workers; nothing else was rendering):
