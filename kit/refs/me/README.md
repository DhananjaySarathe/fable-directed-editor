# Reference photos of the creator

Drop 2-3 sharp, well-lit photos of yourself here (front-facing, eyes to camera, no sunglasses; JPG or PNG). The
thumbnail kit (`kit/thumbs/frames.py`) copies them into each video's `thumbnail/photos/` as `ref_*.jpg`, beside the
frames it pulls from the video, so ChatGPT gets a clean likeness reference.

The photos stay on this Mac: everything here but this README is ignored by git (and so never reaches the public copy).
